Program który przelicza cenę zakupu podaną w Netto na cenę w brutto. 
Wystarczy podać cenę netto (purchaseNet) oraz narzut (markupPercent). Program automatycznie zlicza podane dane oraz wypisuje cenę brutto. 

## Kompilacja
Aby skompilować program z włączonymi wszystkimi ostrzeżeniami, użyj poniższego polecenia w terminalu:

gcc -Wall src/narzut.c -o narzut
